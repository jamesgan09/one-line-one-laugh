A one-line entry for make.fun's one-line-one-laugh bounty. `main.ts` writes a
single funny line to `/output/entry.txt`.

## The line

> My Wi-Fi went down for five minutes today, so I had to talk to my family. They seem nice.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22.18+ (type-stripping runs the `.ts` directly, standard library only).
